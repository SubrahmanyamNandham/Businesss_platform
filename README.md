# Vanguard Digital & Systems | Creative Engineering & Proposal Platform

An enterprise-grade digital agency portfolio and interactive client proposal platform engineered for high-converting business engagements, industry-specific solutions, and executive proposal generation.

---

## Overview & Architecture

Vanguard is designed for modern product studios, software consultancies, and digital agencies that serve diverse sectors including **Education & Campuses**, **Restaurants & Hospitality**, **Startups & Venture MVPs**, **Healthcare**, and **Enterprise Automation**.

### Key Features

1. **Top Bar Contract Navigation**: Strict 3-zone contract with brand wordmark, single-line links, and primary CTA.
2. **Case Studies Archive & Reader**: In-depth modal with problem statement, architectural solution, tech stack, and verified quantitative outcomes.
3. **12-Discipline Services Directory**: Detailed breakdown of business problems, technical solutions, and deliverables for each capability.
4. **8 Specialized Industry Solutions**: Dedicated modules tailored to Education (SIS/ERP), Hospitality (Tableside ordering & KDS), Startups (0-to-1 MVPs), Healthcare (HIPAA patient intake), and Enterprise Automation.
5. **7-Stage Engineering Lifecycle**: Visual project timeline with milestone gates, weekly demos, and guaranteed SLAs.
6. **Executive Client Proposal Platform**:
   - Formatted like a top-tier consulting agreement
   - Milestones and payment schedule with tabular numbers
   - Interactive digital acceptance and authorization sign-off
   - Print & PDF export layout with clean print stylesheets
   - Pre-loaded live proposals (Oakwood Academy ERP, Velvet & Vine Hospitality, FinFlow SaaS MVP)
7. **Studio Command Center (Admin Dashboard)**:
   - Access passcode: `vanguard2026` (or 1-click unlock)
   - Lead & inquiry pipeline management (New, In Discovery, Proposal Sent, Won, Archived)
   - 1-click conversion from inquiry into a custom client proposal
   - Proposal builder & editor with automatic price distribution
   - Portfolio project manager
   - Full JSON state export & backup restoration
8. **Subtle Motion Design**: Smooth Framer Motion transitions with zero layout shift and WCAG compliance.

---

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, custom `@custom-variant dark` support
- **Motion**: Framer Motion (`motion/react`)
- **Icons**: Lucide React
- **State & Storage**: Local persistence with export/import backup capabilities

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/SubrahmanyamNandham/Our-Business-modal.git
cd Our-Business-modal

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will run on `http://localhost:3000`.

### Production Build

```bash
npm run build
npm run preview
```
